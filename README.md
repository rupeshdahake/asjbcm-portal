# ASJBCM Competitive Exam Portal

## Quick Start
```bash
npm install
npm start
```
Open http://localhost:3000

## Admin Login
- Email: administrator@asjbcm.edu
- Password: Vision@2026

## Features
- 57 competitive exam types with 10 model papers each
- 8,000+ questions with quality validation
- AI chatbot for student guidance (GLM-4)
- Web search for latest govt vacancies
- Secure exam mode with anti-cheating
- Marathi medium for MPSC exams
- Scheduled exams (admin creates, students take)
- Topic-wise tests + custom test creator
- Mobile responsive with hamburger menu

## API Endpoints
- POST /api/chat — AI chatbot
- POST /api/search — Web search
- GET /api/exam-updates — Latest notifications
- GET /api/health — Health check
